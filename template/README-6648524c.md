# SFB Staff UI Template

The Six Figure Blueprints /staff shell and Home layout from the supplied source export. Start here for another company and edit `app/staff/branding.ts`. The original staff styles, system font stack, navigation labels, icons and responsive layout are included.

Run `npm install` and `npm run dev`. Open `http://localhost:3000/staff`. Navigation, account popover and theme switching are local UI. Other tabs are empty surfaces for company-specific features. The assistant is a visual placeholder. No APIs, database, authentication, integrations or production records are included.
